# PerfectEHSSolution

Prototype website for a fire safety and HSE training organization.

## Preview locally

Open `index.html` in your browser, or run a simple local server:

```bash
python3 -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080).

## Prototype sections

- Concise navigation menu
- Training calendar (upcoming and recently conducted)
- Training impact summary
- Client list and testimonials
- Contact call-to-action
